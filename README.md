# Wrenspace💫

A digital notebook for handwriting, sketching, and note-taking — built with a stylus and hand-drawing first, the way a real notebook should feel.

## Why
Most note-taking apps are either too limited, too expensive, or simply don't work the way I take notes for varsity. I want to write by hand, sketch with a stylus, and mix drawings with text without fighting the app.
So, why not build exactly what I want?
**WrenSpace** is my upcoming note-taking app, built completely from scratch around the way I actually study.

## Planned features
- Handwriting & stylus support (pressure-sensitive brushes)
- Multiple brush types: fountain pen, ball pen, marker, eraser, ruler
- Add images to pages
- Import and annotate PDFs
- Fixed, notebook-style pages
- Typed text alongside handwriting
- Starts as a web app, later packaged as a mobile app

## Status
🌌Just started — building and learning Flutter/Dart from scratch, one step at a time.

## Tech stack
